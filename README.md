# Explosion_radiuses
A MineCraft Mod that shows the explosion radius of TNT_MINECARTS, TNT, ANCORS. This mod will help you survive explosions, help you learn the best place to stand, helps remove some of the confusion of Explosions. Unupdated: TNT. ANCORS, CRYSTALS. DO NOT SHOW. only TNT MINECARTS. It takes your armor and difficulty for better radius's.
